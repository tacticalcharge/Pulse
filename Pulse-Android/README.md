# Pulse — personal Android Studio source project

A Kotlin / Jetpack Compose Control Center plus Android floating overlay for the Samsung Galaxy Z Flip5 (main screen only).

**Start with [SETUP_WINDOWS.md](SETUP_WINDOWS.md).** This source prototype has **not been compiled or device-tested** in its creation environment and requires Android Studio, API 37 and one-time Gradle wrapper bootstrap.

Major features: configurable floating pill; tap, double tap, sideways swipe and drag; F1 OpenF1 historical replay and session-window detection; basic media/notification integration; floating AI chat via OpenAI Responses API (personal device-side API key, encrypted at rest).

OpenF1 live subscription authentication, production-grade background reliability, Viaplay video integration, cover-screen support and virtual pet are not provided. See guide for details.
