# Pulse v0.3 — Camera-first interaction and OpenF1 pacing

This is source code for GitHub Actions to build. It is **not an APK** and has **not been compiled on an Android toolchain or tested on a Z Flip5** in this environment.

## Five changes requested

1. **Text below camera:** an always camera-sized black circle sits inside a 68×68 dp invisible hit region. The active-status capsule and the expanded dashboard start *below* that region. No text is drawn at the camera's vertical level.
2. **Redesigned expanded panel:** a darker floating sheet, hierarchy with heading and section label, spacious action rows with icon + description, subdued accent highlights, and a 44dp close target. AI / Control Center are no longer a row of plain rectangular buttons.
3. **Easier touch:** the camera touch target increased from 44×44 to 68×68 dp. Tap handling runs on release instead of waiting for the gesture detector's single-tap-confirmation timeout. A separate active capsule is also tappable.
4. **More motion:** spring-like `PathInterpolator` easing, slide-in + fade + slight scale on the active capsule and panel, and a short close animation. This is an Apple-*inspired* motion style, not an exact Dynamic Island reproduction.
5. **OpenF1 rate limits:** one shared limiter for every OpenF1 request (800ms minimum spacing, max 25 per rolling minute), disk cache up to 50 MB for historical JSON responses (24h TTL, 6h for season listings), direct use of the provider's `Retry-After` on 429 and no retry storm. Automatic live schedule checks reduced to at most every 4 minutes and live polling at most every 45 seconds. This reduces traffic but can't guarantee no 429 if other clients share the IP or provider policy changes.

## Installation

For these changes, replace the **entire source project** from this ZIP in your repository, **not** only one `MainActivity.kt`. Ensure the working `build.gradle.kts` **root** and `app/build.gradle.kts` remain in their respective paths. Commit to `main`; download the artifact after a successful Actions run.

## Test on Z Flip5

- Confirm the black dot sits on the camera and text is below the cutout (Samsung may constrain touch/drawing in the status-bar region).
- Tap once near the cutout, double-tap for AI, tap the active capsule, drag vertically, dismiss outside the panel.
- Open the same historical replay twice; the second attempt should reuse local responses. Check a rate-limit message if OpenF1 returns HTTP 429.
- Confirm cached sessions update eventually (season listings expire after six hours; other historical responses after 24 hours).
