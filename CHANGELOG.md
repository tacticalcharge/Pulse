# Changelog

## 0.2.0 — Dynamic camera island refresh

1. Free vertical dragging; long-press for 2D dragging; auto camera anchor, adjustable Y offset and dot diameter, reset-to-camera.
2. OLED-dark overlay and Control Center with smoother transitions and configurable accent colors.
3. Actual circuit-path outline from OpenF1 one-lap location samples, approximate moving marker, position table, race-control/pit events, weather when available.
4. Expanded pill collapses on outside touch where the Android overlay system delivers ACTION_OUTSIDE; always has a close button.
5. Central camera gap avoids text on the hole-punch area; idle dot uses a camera-derived diameter when Android exposes it.
6. Cleaner Compose five-tab bottom navigation.
7. Grouped circuit/session browser with year, search and filter.
8. Stop replay clears F1 timeline and returns to idle; separate master F1 toggle.
9. No idle F1 banner — camera-only idle display when no active content.

Basic overlay, OpenAI chat, OpenF1 historical replay, media / notification integration and feature settings.
